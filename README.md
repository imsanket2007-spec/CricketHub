🏏 Cricket Hub

Cricket News and Updates Application

Cricket Hub is a mobile application developed using React Native and Expo. It provides cricket enthusiasts with the latest cricket news, user authentication, favorite article management, and a simple user-friendly interface.

🚀 Features

- Splash Screen with Cricket Hub App Icon
- User Registration and Login
- Firebase Authentication
- Cloud Firestore Database
- Latest Cricket News using News API
- Save and Manage Favorite Articles
- News Article Details
- User Profile
- Bottom Tab Navigation
- React Native Paper UI Components
- Firebase Firestore Security Rules

⚙️ Installation

1. Clone or download the repository.

2. Open the project folder in VS Code.

3. Install dependencies:
   
   "npm install"

4. Configure Firebase in "src/services/FirebaseConfig.js".

5. Add your News API key in "NewsScreen.js".

6. Start the Expo development server:
   
   "npx expo start"

7. Scan the QR code using Expo Go.

🔥 Firebase Configuration

Cricket Hub uses Firebase Authentication and Cloud Firestore.

Firebase provides:

- User authentication
- User profile storage
- Favorite article storage
- Database security rules

🌐 External API

The application uses News API to retrieve cricket-related news articles.

Website: https://newsapi.org/

A valid API key is required to fetch news.
